# Developer Internship Project

Simple user authentication system built using:

- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery AJAX
- PHP
- MySQL
- Redis
- MongoDB

## Features

- User Registration
- User Login
- Profile Management
- AJAX-based frontend/backend communication
- Redis session storage
- MongoDB profile storage
- MySQL authentication storage

## Project Structure

css/
js/
php/
register.html
login.html
profile.html
index.html
database.sql

## How to Run

1. Start Apache and MySQL in XAMPP
2. Import database.sql into phpMyAdmin
3. Configure MongoDB and Redis
4. Open http://localhost/arjun-task/
